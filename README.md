# COSMIC DISCOVERY – اكتشف أسرار الكون
### رحلة علمية بين آيات القرآن وأسرار الكون
### Cosmic Science & Islamic Knowledge Platform

---

## 1. نظرة عامة على المنصة (Platform Overview)
تمت ترقية وهندسة المنصة الحالية بالكامل لتصبح منصة علمية وبحثية تفاعلية متطورة متخصصة في علوم الفضاء والفلك والفيزياء الكونية، مع دراسة موثقة ومنضبطة لأوجه التأمل الإيماني بين الآيات القرآنية الكريمة والمعطيات العلمية الحديثة.

### اللغات المدعومة (Multilingual Architecture)
- **العربية (اللغة الأساسية)**: دعم كامل لاتصال الحروف والخطوط المتخصصة واتجاه الكتابة من اليمين لليسار (`dir="rtl"`).
- **English**: Full internationalization with left-to-right flow (`dir="ltr"`).
- **Français**: Traduction intégrale scientifique et navigation (`dir="ltr"`).

## 2. الأقسام الرئيسية في المنصة (Core Modules)
1. **موسوعة الكون والمجرات (Universe & Galaxies Encyclopedia)**:
   - مجرة درب التبانة، أندروميدا، الشبكة الكونية الكبرى، العناقيد المجرية.
2. **موسوعة النجوم (Stars Encyclopedia)**:
   - دورات حياة النجوم، العمالقة الحمر، النجوم النيوترونية، المستعرات العظمى.
3. **الكواكب والمجموعة الشمسية (Planets & Solar System)**:
   - محاكي مداري تفاعلي للشمس والكواكب الثمانية وتفاصيل الأقطار والأقمار.
4. **الثقوب السوداء (Black Holes & Singularities)**:
   - دراسة أفق الحدث، أقراص الانجذاب، ثقب TON 618، والرامي أ*.
5. **السدم والمجرات البعيدة (Nebulae & Deep Space)**:
   - أعمدة الخلق، سديم الجبار، سديم الجؤجؤ، صور JWST بالأشعة تحت الحمراء.
6. **المسافات والأبعاد الكونية (Cosmic Distances & Scales)**:
   - حاسبة سرعة الضوء التفاعلية لحساب زمن وصول الفوتونات بدقة $299,792.458$ كم/ثانية.
   - مستكشف المقاييس الكونية (Scale Explorer) عبر 26 رتبة مقدار من الإنسان إلى الكون المنظور.
7. **أسرار نشأة الكون (Cosmology & Origin of the Universe)**:
   - الانفجار العظيم، إشعاع الخلفية الكونية الميكروي (CMB)، الطاقة المظلمة وتمدد الزمكان.
8. **الرحلات الافتراضية في الفضاء (Virtual Space Journeys)**:
   - محاكي مداري حي ثلاثي الأبعاد/كانفاس مع التحكم في سرعة المدارات والتكبير والتصغير ومتابعة التليمتري لكل جرم.
   - مقارن الأجرام الكونية (Celestial Comparator) للمقارنة النسبية بين الحجوم والأقطار.
9. **أحدث الاكتشافات الفلكية (Latest Astronomical Discoveries)**:
   - اكتشافات تلسكوب جيمس ويب (JWST)، موجات الجاذبية (LIGO/Virgo)، والغلاف الجوي للكواكب الخارجية.
10. **القرآن الكريم والكون (The Holy Quran & The Universe)**:
    - دراسة آيات التمدد (الذاريات 47)، الانفصال والرتق (الأنبياء 30)، السباحة المدارية (الأنبياء 33)، النجم الثاقب (الطارق 1-3)، وإنزال الحديد (الحديد 25).
    - تفاسير معتمدة (ابن كثير، الطبري، القرطبي، السعدي).
    - ضوابط منهجية صارمة تمنع التكلف وتفصل بين النص الشرعي والنظريات الفيزيائية القابلة للتطور.
11. **التأملات العلمية والإيمانية (Scientific & Faith Reflections)**:
    - مقالات وبحوث تستحضر عظمة الخالق وإتقان الصنع.
12. **اختبر معلوماتك العلمية (Interactive Cosmic Quiz)**:
    - اختبارات علمية متدرجة (مبتدئ، متوسط، باحث) مع تقديم فوري للشرح العلمي والمراجع وتقييم الدرجات والرتب الكونية.

## 3. تكامل الذكاء الاصطناعي (Gemini AI Cosmic Lab)
- استخدام نموذج `gemini-3.8-flash` عبر الخادم الخلفي الآمن (`/server.ts`) دون تسريب المفاتيح للواجهة.
- 4 مسارات بحثية ذكية:
  1. **اسأل باحث الفلك**: إجابات فلكية موثقة ومعللة.
  2. **توليد مقال فلكي**: إنتاج مقالات منظمة (شرح مبسط، تحليل متقدم، مواصفات، مراجع).
  3. **مقارنة فلكية ذكية**: دراسة مقارنة بين جرمين سماويين.
  4. **تأمل إيماني منضبط**: ربط بين الآيات القرآنية والحقائق الفلكية مع التقيد الصارم بالتفاسير المعتمدة.
- إمكانية حفظ مخرجات الذكاء الاصطناعي كمسودات تراجعها الإدارة قبل النشر.

---

## 4. لوحة تحكم الإدارة (Admin Dashboard)
- **إدارة المقالات**: إضافة مقال جديد مع كافة الحقول الفلكية (قطر، كتلة، حرارة، مسافة، شرح مبسط ومتقدم)، التعديل، والحذف.
- **مراجعة مسودات الذكاء الاصطناعي**: مراجعة مقالات Gemini واعتمادها بنقرة واحدة ونشرها للمستخدمين.
- **إحصائيات المنصة**: متابعة عدد المقالات، الزيارات، الاختبارات المكتملة، واستفسارات الذكاء الاصطناعي.

---

## 5. البنية التقنية والتشغيل (Architecture & Development)
- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Canvas API.
- **Backend**: Express 4, Node.js, `@google/genai` SDK (`^3.0.0`).
- **Tests**: اختبارات منطقية سريعة ومحددة ومستقلة باستخدام `node:test` و `node:assert/strict`.

### أوامر التشغيل
```bash
# تشغيل خادم التطوير الشامل (Frontend + Backend)
npm run dev

# فحص أنواع TypeScript والتأكد من خلو المشروع من الأخطاء
npm run lint

# تشغيل الاختبارات البرمجية للمنطق الفلكي
npx --yes tsx --test src/utils/cosmicCalculations.test.ts

# بناء المشروع للإنتاج
npm run build

# تشغيل خادم الإنتاج
npm start
```
